为什么用这个思路？
顺时针旋转 90° 可以拆成两个简单操作：先沿主对角线翻转，再左右翻转。每步都有明确的坐标对应关系，原地完成，不需要额外矩阵。

题目描述

给定一个 n × n 的二维矩阵表示图像，将其原地顺时针旋转 90 度。

示例：
[[1,2,3],[4,5,6],[7,8,9]] → [[7,4,1],[8,5,2],[9,6,3]]

图解即思路

① 原矩阵
② 沿主对角线翻转（matrix[i][j] ↔ matrix[j][i]）
③ 左右翻转 → 旋转结果
结论
先对角线翻转，再左右翻转，两步叠加正好等于顺时针 90°。

最优解代码

Python

def rotate(matrix):
    n = len(matrix)
    for i in range(n):              # 主对角线翻转
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for i in range(n):              # 左右翻转
        matrix[i].reverse()

Java

public void rotate(int[][] matrix) {
    int n = matrix.length;
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++) {
            int t = matrix[i][j]; matrix[i][j] = matrix[j][i]; matrix[j][i] = t;
        }
    for (int i = 0; i < n; i++) {
        int l = 0, r = n - 1;
        while (l < r) { int t = matrix[i][l]; matrix[i][l] = matrix[i][r]; matrix[i][r] = t; l++; r--; }
    }
}

复杂度分析

  • 时间：O(n²) — 每个元素处理常数次
  • 空间：O(1) — 原地

易错点

  • 对角线翻转只遍历上三角：j 从 i+1 开始，否则交换两次等于没换
  • 逆时针要换顺序：逆时针 90° 是先左右翻转再对角线翻转，方向别弄反
自我检验

Q: 为什么两步叠加等于旋转 90°？

答： 对角线翻转把 (i,j) 映到 (j,i)，左右翻转再把列镜像为 n-1-j，最终 (i,j)→(j,n-1-i)，正是顺时针 90° 的坐标变换。

Q: 能否一次循环直接旋转？

答： 可以，按「一圈一圈」处理四个角的值循环交换，但两步分解更直观、不易错。
