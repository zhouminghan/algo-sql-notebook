🤔 为什么用这个思路？
最少完全平方数个数 = 最少硬币问题。dp[i] = min(dp[i - j*j]) + 1，j 遍历所有小于 i 的平方数。也可用 BFS（层数即个数）。

📄 题目描述

给定整数 n，返回和为 n 的完全平方数的最少数量。完全平方数是 1、4、9、16… 这样的数。

示例：
n=12 → 3（4+4+4）；n=13 → 2（4+9）

📐 图解即思路

① dp[i] = min(dp[i - 平方数]) + 1
② n=12：12-4=8(dp=2)、12-9=3(dp=3)、12-1=11(dp=3)，min=2+1=3
✅ 结论
枚举最后一个平方数，取剩余部分的最小拆分数 + 1。

📝 最优解代码

Python

def numSquares(n):
    dp = [0] + [float('inf')] * n
    for i in range(1, n + 1):
        j = 1
        while j * j <= i:
            dp[i] = min(dp[i], dp[i - j * j] + 1)
            j += 1
    return dp[n]

Java

public int numSquares(int n) {
    int[] dp = new int[n + 1];
    Arrays.fill(dp, Integer.MAX_VALUE);
    dp[0] = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j * j <= i; j++)
            dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
    return dp[n];
}

⏱ 复杂度分析

  • 时间：O(n · √n)
  • 空间：O(n)

⚠️ 易错点

  • dp[0]=0：边界 0 需要 0 个平方数
  • 枚举 j*j <= i：只枚举不超过 i 的平方数
🧪 自我检验

Q: BFS 怎么做？

✅ 答： 从 n 出发，每层减去一个平方数，第一次减到 0 的层数就是答案。

Q: 四平方和定理？

✅ 答： 任意正整数可表为至多 4 个平方数之和，是这题的理论上界。
