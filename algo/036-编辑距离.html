🤔 为什么用这个思路？
把两个串的前缀对齐：dp[i][j] 表示 word1 前 i 个字符变成 word2 前 j 个字符的最少操作数。三选一取最小——插入、删除、替换（相等则直接继承）。

📄 题目描述

给定两个单词 word1 和 word2，求将 word1 转换成 word2 所需的最少操作数。可进行的操作：插入一个字符、删除一个字符、替换一个字符。

示例：
word1="horse", word2="ros" → 3（horse→rorse→rose→ros）

📐 图解即思路

① dp[i][j]：word1 前 i 个 → word2 前 j 个的最少操作
② 三选一：插入 dp[i][j-1]+1、删除 dp[i-1][j]+1、替换 dp[i-1][j-1]+1
✅ 结论
字符相等就白拿对角线值，否则在插入/删除/替换里取最小并 +1，右下角即答案。

📝 最优解代码

Python

def minDistance(word1, word2):
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1): dp[i][0] = i
    for j in range(n + 1): dp[0][j] = j
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1
    return dp[m][n]

Java

public int minDistance(String w1, String w2) {
    int m = w1.length(), n = w2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++) {
            if (w1.charAt(i - 1) == w2.charAt(j - 1)) dp[i][j] = dp[i - 1][j - 1];
            else dp[i][j] = Math.min(Math.min(dp[i - 1][j], dp[i][j - 1]), dp[i - 1][j - 1]) + 1;
        }
    return dp[m][n];
}

⏱ 复杂度分析

  • 时间：O(m · n)
  • 空间：O(m · n) — 可滚动优化到 O(n)

⚠️ 易错点

  • 三选一别漏：插入、删除、替换对应三个方向，忘掉任何一个都会高估操作数
  • 相等直接继承：word1[i-1]==word2[j-1] 时 dp[i][j]=dp[i-1][j-1]，不用 +1
🧪 自我检验

Q: 两个空串？

✅ 答： m=n=0，dp[0][0]=0，返回 0。

Q: 「horse」→「ros」为何是 3 步？

✅ 答： h→r 替换(1)、删 e(1)、替换 s→? 实际路径：删 h、r 不变、o 不变、r→s? 对照 dp 表右下角即 3，具体路径可用回溯 dp 表还原。
