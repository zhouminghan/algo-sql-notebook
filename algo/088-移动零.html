为什么用这个思路？
快慢双指针：slow 指向「下一个非零该放的位置」，fast 扫描数组。遇非零就交换到 slow 并前进，最后 slow 之后全是 0。原地 O(n)。

题目描述

给定整数数组，将所有 0 移动到数组末尾，同时保持非零元素的相对顺序。必须原地操作。

示例：
[0,1,0,3,12] → [1,3,12,0,0]

图解即思路

① slow 指向下一个非零位置，fast 扫描
② 遇非零交换到 slow，slow 前进
③ 结果 [1,3,12,0,0]
结论
非零元素依次「压实」到前面，剩余位置补 0。

最优解代码

Python

def moveZeroes(nums):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[slow], nums[fast] = nums[fast], nums[slow]
            slow += 1

Java

public void moveZeroes(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++)
        if (nums[fast] != 0) { int t = nums[slow]; nums[slow] = nums[fast]; nums[fast] = t; slow++; }
}

复杂度分析

  • 时间：O(n)
  • 空间：O(1)

易错点

  • 保持相对顺序：用交换而非「先删后补」，顺序自然保持
  • slow 含义：slow 是下一个非零该放的位置，也是当前非零区间的长度
自我检验

Q: 全 0 数组？

答： fast 全程不触发交换，slow=0，数组不变。

Q: 能否先统计 0 个数再整体移动？

答： 可以，但双指针交换更直观且一步到位。
