为什么用这个思路？
中序遍历的顺序是「左 → 根 → 右」。递归一行就够；迭代则用栈模拟「一直往左走，到底弹出访问，再转右子树」，是理解二叉树遍历的基础。

题目描述

给定二叉树的根节点，返回它的中序遍历。

示例：
树 [1,null,2,3] → [1,3,2]

图解即思路

① 中序：左 → 根 → 右
② 迭代：一直向左压栈，到底后弹出访问，再转右
③ 访问顺序 [1,3,2]
结论
「左-根-右」递归即答案；迭代栈版本在面试中常被要求手写。

最优解代码

Python

def inorderTraversal(root):
    res = []
    def dfs(node):
        if not node:
            return
        dfs(node.left)
        res.append(node.val)
        dfs(node.right)
    dfs(root)
    return res

Java

public List<Integer> inorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> st = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !st.isEmpty()) {
        while (cur != null) { st.push(cur); cur = cur.left; }
        cur = st.pop();
        res.add(cur.val);
        cur = cur.right;
    }
    return res;
}

复杂度分析

  • 时间：O(n) — 每个节点访问一次
  • 空间：O(h) — 栈深度，h 为树高

易错点

  • 遍历顺序：先递归左子树、再访问根、最后右子树，顺序记牢
  • 迭代的 cur 移动：压栈时 cur=cur.left，弹出访问后 cur=cur.right，缺一步就死循环
自我检验

Q: 空树？

答： root 为 None，直接返回空列表。

Q: 前序、后序与中序差在哪？

答： 只差「访问根」的时机：前序在入栈前访问，中序在出栈时访问，后序在左右都处理完再访问。
