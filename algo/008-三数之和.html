008

三数之和

中等 双指针 排序
→ LeetCode 原题
🤔 为什么排序 + 双指针？
暴力 O(n³)。排序后固定一个数，剩下两数用双指针在有序数组上 O(n) 求解，总 O(n²)。排序同时方便去重。

📄 题目描述

给你一个整数数组 nums，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k，同时还满足 nums[i] + nums[j] + nums[k] == 0。返回所有和为 0 且不重复的三元组。

示例：

输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：nums[0]+nums[1]+nums[2]=(-1)+0+1=0

📐 图解即思路

🎯 固定 + 双指针
排序 → 遍历 i 作为第一个数 → left=i+1, right=n-1 双指针找两数之和 = -nums[i]。和 < target 则 left++，> target 则 right--。注意去重。
① 排序后：[-4,-1,-1,0,1,2]，i=0, left=1, right=5
② i=0(-4): left+right=-1+2=1 < 4 → left++
③ i=1(-1): left=2(-1), right=5(2) → -1+2=1 == 1 ✓ 找到[-1,-1,2]
④ i=2(-1): 跳过重复，i=3(0): left=4(1), right=5(2) → 1+2=3 > 0 → right--
⑤ i=3(0): left=4(1), right=5(2): 1+2≠0, 结果 [[-1,-1,2],[-1,0,1]]
✅ 结论
排序 O(nlogn) + 双指针 O(n²) = O(n²)。去重是关键：跳过相同的 i 值，找到答案后跳过重复的 left 和 right。

📝 最优解代码

Python

def threeSum(nums):
    nums.sort()
    res = []
    n = len(nums)

    for i in range(n - 2):
        if i > 0 and nums[i] == nums[i-1]:
            continue
        left, right = i + 1, n - 1
        while left < right:
            total = nums[i] + nums[left] + nums[right]
            if total < 0:
                left += 1
            elif total > 0:
                right -= 1
            else:
                res.append([nums[i], nums[left], nums[right]])
                while left < right and nums[left] == nums[left+1]:
                    left += 1
                while left < right and nums[right] == nums[right-1]:
                    right -= 1
                left += 1; right -= 1
    return res

Java

public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> res = new ArrayList<>();
    int n = nums.length;

    for (int i = 0; i < n - 2; i++) {
        if (i > 0 && nums[i] == nums[i-1]) continue;
        int left = i + 1, right = n - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum < 0) left++;
            else if (sum > 0) right--;
            else {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                while (left < right && nums[left] == nums[left+1]) left++;
                while (left < right && nums[right] == nums[right-1]) right--;
                left++; right--;
            }
        }
    }
    return res;
}

⏱ 复杂度分析

  • 时间：O(n²) — 排序 O(nlogn) + 双指针 O(n²)
  • 空间：O(1) — 不计返回结果

⚠️ 易错点

  • 去重三处：i 跳过重复值，找到答案后 left 和 right 也需跳过重复值
  • 跳过 i 的条件：if i > 0 and nums[i] == nums[i-1]，不能写成 nums[i] == nums[i+1]，后者会漏掉第一个
🧪 自我检验

Q1: nums=[0,0,0,0]，结果是什么？

✅ 答：[[0,0,0]]。 i=0 时找到 [0,0,0]，去重后 left/right 跳过重复 0。i=1,2,3 的 nums[i]=0 被跳过，最终只有一个结果。

Q2: 为什么排序不会影响结果？

✅ 答：题目要求的是值的三元组，不是下标。 排序后双指针需要有序数组才能正确收缩。去重也依赖排序使相同值相邻。
