🤔 为什么用滑动窗口？
暴力枚举所有子串 O(n³)。滑动窗口 + HashSet：右指针扩展窗口，遇到重复时左指针收缩，每个字符最多访问两次，O(n) 时间。

📄 题目描述

给定一个字符串 s，请你找出其中不含有重复字符的 最长子串 的长度。

示例：

输入：s = "abcabcbb"
输出：3
解释：最长无重复子串是 "abc"，长度为 3

📐 图解即思路

🪟 滑动窗口核心
维护 [left, right] 区间不含重复字符。right 右移扩展窗口，用 Set 记录窗口内字符。若 s[right] 已存在，left 右移并移除 s[left]，直到窗口无重复。每步更新 maxLen。
① left=0, right=0, set={}, 'a' 不重复 → 加入, maxLen=1
② right=1, set={'a'}, 'b' 不重复 → 加入, maxLen=2
③ right=2, set={'a','b'}, 'c' 不重复 → 加入, maxLen=3
④ right=3, s[3]='a' 重复！left 右移收缩窗口
⑤ 继续扫描到末尾，最终 maxLen=3
✅ 结论
滑动窗口核心：右指针扩张找可行解，左指针收缩找最优解。每个字符最多进/出窗口各一次，O(n)。Set 保证 O(1) 查重。

📝 最优解代码

Python

def lengthOfLongestSubstring(s: str) -> int:
    seen = set()
    left = 0
    max_len = 0

    for right in range(len(s)):
        while s[right] in seen:
            seen.remove(s[left])
            left += 1
        seen.add(s[right])
        max_len = max(max_len, right - left + 1)

    return max_len

Java

public int lengthOfLongestSubstring(String s) {
    Set<Character> set = new HashSet<>();
    int left = 0, maxLen = 0;

    for (int right = 0; right < s.length(); right++) {
        while (set.contains(s.charAt(right))) {
            set.remove(s.charAt(left));
            left++;
        }
        set.add(s.charAt(right));
        maxLen = Math.max(maxLen, right - left + 1);
    }

    return maxLen;
}

⏱ 复杂度分析

  • 时间：O(n) — 每个字符最多被访问两次（right 和 left 各一次）
  • 空间：O(min(m, n)) — m 为字符集大小，n 为字符串长度

⚠️ 易错点

  • 必须用 while 而非 if：窗口中有多个重复字符时，需要一直收缩直到移除所有重复。例如 s="pwwkew"，当 right=2 时 'w' 重复，需 left 从 0 收缩到 2
  • maxLen 更新位置：每次 right 扩展后都要更新 maxLen，而非只在无重复时更新
🧪 自我检验

Q1: 如果 s = "pwwkew"，最长无重复子串是什么？

✅ 答："wke"，长度为 3。 注意 "pwke" 是子序列不是子串。当 right=2 时 'w' 重复，left 从 0 收缩到 2，窗口变为 [2,2]；之后扩展到 [2,4]="wke"，maxLen=3。

Q2: 能否用数组代替 HashSet 优化？

✅ 答：可以。 如果字符集已知（如 ASCII 128），用 int[128] 存最近出现位置，遇到重复直接跳 left = max(left, lastPos[c] + 1)，无需 while 循环。时间仍是 O(n) 但常数更小。
