为什么用这个思路？
维护一个「无重复字符」的窗口，右指针扩张、左指针在遇到重复时收缩。用哈希集合记录窗口内字符，O(n) 一次扫完。

题目描述

给定字符串，找出其中不含重复字符的最长子串的长度。

示例：
"abcabcbb" → 3（abc）；"bbbbb" → 1

图解即思路

① 右指针扩张，字符进集合
② 遇到重复 a，左指针收缩到重复之后
③ 全程记录窗口最大长度
结论
窗口内始终无重复，右扩左缩，记录最大宽度。

最优解代码

Python

def lengthOfLongestSubstring(s):
    window = set()
    l = ans = 0
    for r, ch in enumerate(s):
        while ch in window:
            window.remove(s[l])
            l += 1
        window.add(ch)
        ans = max(ans, r - l + 1)
    return ans

Java

public int lengthOfLongestSubstring(String s) {
    Set<Character> set = new HashSet<>();
    int l = 0, ans = 0;
    for (int r = 0; r < s.length(); r++) {
        while (set.contains(s.charAt(r))) set.remove(s.charAt(l++));
        set.add(s.charAt(r));
        ans = Math.max(ans, r - l + 1);
    }
    return ans;
}

复杂度分析

  • 时间：O(n) — 左右指针各走一遍
  • 空间：O(字符集) — 集合

易错点

  • 左指针要 while 收缩：重复字符可能在窗口内部，需一直删到把重复字符移除为止
  • 更新答案的时机：每次右扩后都要用 r-l+1 更新最大
自我检验

Q: "pwwkew" 答案？

答： 3（wke）。遇到第二个 w 时左指针跳到第一个 w 之后。

Q: 为什么用 while 不用 if？

答： 重复字符位置不确定，if 只删一个可能删不掉窗口里的那个重复字符。
