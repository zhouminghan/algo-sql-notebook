为什么用这个思路？
卖出后次日不能买入。用三状态 DP：hold（持有）、sold（刚卖出）、rest（空仓休息）。每天三态互相转移，最终答案是 max(sold, rest)。

题目描述

可以多次买卖，但卖出后存在一天冷冻期：卖出股票的次日不能买入。求最大利润。

示例：
[1,2,3,0,2] → 3（买 1 卖 2、冷冻、买 0 卖 2）

图解即思路

① 三状态：持有 hold / 刚卖 sold / 空仓 rest
② 状态转移
③ 答案 = max(sold, rest) = 3
结论
冷冻期体现在「买入只能来自空仓状态」，即不能昨天刚卖今天买。

最优解代码

Python

def maxProfit(prices):
    hold = float('-inf')
    sold = rest = 0
    for p in prices:
        new_hold = max(hold, rest - p)
        new_sold = hold + p
        new_rest = max(rest, sold)
        hold, sold, rest = new_hold, new_sold, new_rest
    return max(sold, rest)

Java

public int maxProfit(int[] prices) {
    int hold = Integer.MIN_VALUE, sold = 0, rest = 0;
    for (int p : prices) {
        int nh = Math.max(hold, rest - p);
        int ns = hold + p;
        int nr = Math.max(rest, sold);
        hold = nh; sold = ns; rest = nr;
    }
    return Math.max(sold, rest);
}

复杂度分析

  • 时间：O(n)
  • 空间：O(1)

易错点

  • 买入依赖 rest：new_hold 用 rest-p 而非 sold-p，体现冷冻期
  • 状态同时更新：先算新值再统一赋值，避免同一天状态串味
自我检验

Q: 为什么要有 sold 状态？

答： 若只有持有/空仓，无法表达「昨天刚卖今天不能买」，sold 专门标记刚卖出。

Q: 最后一天可能持有吗？

答： 不可能是最优，答案取 max(sold, rest)，排除仍持有未卖出的情况。
