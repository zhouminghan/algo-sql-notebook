为什么用这个思路？
相邻房屋不能同时偷。dp[i] = max(dp[i-1], dp[i-2] + nums[i])：要么不偷当前、要么偷当前加上前两家的最优。滚动两个变量 O(1) 空间。

题目描述

你是一排房屋，每间屋内有一定现金。相邻房屋装有报警器，如果相邻房屋同一晚被闯入会自动报警。求不触发警报的前提下能偷到的最高金额。

示例：
[1,2,3,1] → 4（偷 1 和 3）；[2,7,9,3,1] → 12

图解即思路

① dp[i] = max(dp[i-1], dp[i-2]+nums[i])
② 偷当前 = dp[i-2]+nums[i]，不偷 = dp[i-1]
结论
相邻约束让「当前偷不偷」只依赖前两家，滚动即可。

最优解代码

Python

def rob(nums):
    prev2 = prev = 0
    for x in nums:
        prev2, prev = prev, max(prev, prev2 + x)
    return prev

Java

public int rob(int[] nums) {
    int prev2 = 0, prev = 0;
    for (int x : nums) {
        int cur = Math.max(prev, prev2 + x);
        prev2 = prev; prev = cur;
    }
    return prev;
}

复杂度分析

  • 时间：O(n)
  • 空间：O(1)

易错点

  • 初始化 0：prev2=prev=0，处理空数组与第一家
  • 别贪心隔一个偷：隔一个偷未必最优，必须 DP 比较「偷当前」与「不偷当前」
自我检验

Q: [2,1,1,2] 答案？

答： 偷 0 和 3 得 4。贪心隔一偷会错过。

Q: 首尾相连（打家劫舍 II）呢？

答： 分别算「去掉第一家」和「去掉最后一家」取较大者。
