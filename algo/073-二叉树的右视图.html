🤔 为什么用这个思路？
右视图 = 每一层最右边的节点。层序遍历时，每层最后一个访问到的节点就是该层右视图。

📄 题目描述

给定二叉树，想象站在它的右侧，返回从顶部到底部能看到的节点值。

示例：
[1,2,3,null,5,null,4] → [1,3,4]

📐 图解即思路

① 每层最右的节点进入右视图
② 层序遍历取每层最后一个
✅ 结论
BFS 每层记录最后一个节点即可。

📝 最优解代码

Python

from collections import deque
def rightSideView(root):
    if not root:
        return []
    res, q = [], deque([root])
    while q:
        for i in range(len(q)):
            node = q.popleft()
            if i == len(q):      # 等价于每层最后一个
                res.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
    return res

Java

public List<Integer> rightSideView(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new LinkedList<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int size = q.size();
        for (int i = 0; i < size; i++) {
            TreeNode n = q.poll();
            if (i == size - 1) res.add(n.val);
            if (n.left != null) q.offer(n.left);
            if (n.right != null) q.offer(n.right);
        }
    }
    return res;
}

⏱ 复杂度分析

  • 时间：O(n)
  • 空间：O(n) — 队列

⚠️ 易错点

  • 取每层最后一个：i == size-1 时收集，不是第一个
  • 空树返回 []：root 为 None 直接返回空
🧪 自我检验

Q: DFS 能做吗？

✅ 答： 可以，先右后左的 DFS，每个深度第一次访问到的节点就是右视图。

Q: 为什么不用「一直往右走」？

✅ 答： 右视图不一定是右链，左子树的右子节点也可能被看到，必须逐层判断。
