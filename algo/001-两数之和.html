为什么用这个思路？
暴力双循环是 O(n²)。用哈希表一边遍历一边查「补数」，把查找从 O(n) 降到 O(1)，一次遍历 O(n) 就能出结果。

题目描述

给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出和为目标值的那 两个整数，并返回它们的数组下标。假设每种输入只对应一个答案，且不能使用两次相同元素。

示例：
nums=[2,7,11,15], target=9 → [0,1]

图解即思路

① i=0，nums[0]=2，补数 7 不在表 → 存入 2→0
② i=1，nums[1]=7，补数 2 命中！
③ 一次遍历，边查边存
结论
先查补数、再存当前值，一次遍历即可命中。

最优解代码

Python

def twoSum(nums, target):
    seen = {}  # val -> index
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []

Java

public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int c = target - nums[i];
        if (map.containsKey(c)) return new int[]{map.get(c), i};
        map.put(nums[i], i);
    }
    return new int[]{};
}

复杂度分析

  • 时间：O(n) — 一次遍历
  • 空间：O(n) — 哈希表

易错点

  • 先查后存：先存再查可能把同一个元素用两次（如 target=6, nums=[3,2,4] 会错误返回 [0,0]）
  • 哈希冲突：Java HashMap 链表过长会转红黑树，但两数之和场景不会触发
自我检验

Q: nums 有重复元素如 [3,3] 还正确吗？

答： 正确。i=0 时表空查不到 3，存 (3,0)；i=1 时查 complement=3 命中，返回 [0,1]。

Q: 要返回所有不重复配对怎么办？

答： 排序 + 双指针，或用 Set 去重配对结果。
