🤔 为什么用双指针？
暴力 O(n²) 枚举所有组合。双指针从两端向中间收缩：面积由较短的柱子决定，移动较短的一边才有可能找到更大的面积。O(n) 时间。

📄 题目描述

给定一个长度为 n 的整数数组 height。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i])。

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。返回容器可以储存的最大水量。

示例：

输入：height = [1,8,6,2,5,4,8,3,7]
输出：49
解释：选择索引 1 和 8（高度 8 和 7），宽度 7，面积 = min(8,7) × 7 = 49

📐 图解即思路

↔️ 双指针收缩
left=0, right=n-1。面积 = min(h[left], h[right]) × (right - left)。移动较短的一边（因为宽度在缩小，只有提高较短边才可能增大面积）。
① left=0, right=8：min(1,7)×8=8，left 较短 → 右移
② left=1, right=8：min(8,7)×7=49，right 较短 → 左移
③ left=1, right=6：min(8,8)×5=40，right 左移
④ 继续收缩直到 left=right，maxArea=49
✅ 结论
贪心正确性：宽度缩小时，移动较短边是唯一可能增大面积的方式（因为面积由 min(h[l],h[r]) 决定）。O(n) 时间，O(1) 空间。

📝 最优解代码

Python

def maxArea(height):
    left, right = 0, len(height) - 1
    max_area = 0

    while left < right:
        h = min(height[left], height[right])
        max_area = max(max_area, h * (right - left))
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1

    return max_area

Java

public int maxArea(int[] height) {
    int left = 0, right = height.length - 1;
    int maxArea = 0;

    while (left < right) {
        int h = Math.min(height[left], height[right]);
        maxArea = Math.max(maxArea, h * (right - left));
        if (height[left] < height[right]) {
            left++;
        } else {
            right--;
        }
    }

    return maxArea;
}

⏱ 复杂度分析

  • 时间：O(n) — 双指针各走一次
  • 空间：O(1)

⚠️ 易错点

  • 移动哪边：必须移动较短的一边。移动较高边，宽度减小而高度不会增加，面积一定变小
  • 相等时移动哪边：两边高度相等时，移动任意一边都不影响正确性，因为无论移动哪边，新面积不会更大
🧪 自我检验

Q1: 为什么移动较短边是正确的？

✅ 答：面积由短板决定。 设 left 较短，移动 right（较长边）→ 新宽度变小，新高度 ≤ height[left]（短板不变或更短），面积一定 ≤ 当前面积。所以只有移动短板才可能找到更大的面积。

Q2: height=[1,1]，面积是多少？

✅ 答：1。 min(1,1) × (1-0) = 1。两边相等，移动任意一边后 left=right 循环结束。
