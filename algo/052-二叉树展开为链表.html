为什么用这个思路？
按「前序」的顺序把树展平成右链表。逆前序（右→左→根）遍历，用一个全局 prev 记录上一个访问节点，把当前节点右指针接到 prev、左指针置空即可，原地完成。

题目描述

给定二叉树根节点，将其原地展开为单链表：展开后的链表顺序为前序遍历顺序，每个节点左指针为 null、右指针指向下一个节点。

示例：
[1,2,5,3,4,null,6] → [1,null,2,null,3,null,4,null,5,null,6]

图解即思路

① 原树：前序顺序 1→2→3→4→5→6
② 逆前序（右→左→根）串成右链
结论
逆前序保证「下一个该接的节点」已经处理完，prev 始终指向链表头部。

最优解代码

Python

def flatten(root):
    prev = [None]
    def dfs(node):
        if not node:
            return
        dfs(node.right)     # 逆前序：右
        dfs(node.left)      # 左
        node.right = prev[0]  # 根：接上已串好的链表
        node.left = None
        prev[0] = node
    dfs(root)

Java

TreeNode prev = null;
public void flatten(TreeNode root) {
    if (root == null) return;
    flatten(root.right);
    flatten(root.left);
    root.right = prev;
    root.left = null;
    prev = root;
}

复杂度分析

  • 时间：O(n)
  • 空间：O(h) — 递归栈

易错点

  • 左指针置空：展平后每个节点 left 必须是 null，漏掉会残留旧结构
  • 先右后左：逆前序顺序是 右→左→根，顺序错了链表次序不对
自我检验

Q: 为什么用逆前序而不是前序？

答： 前序先访问根时，它的右子树还没处理，根无法指向「已串好的后续」；逆序则保证后续已就绪。

Q: O(1) 额外空间做法？

答： 用「找左子树最右节点，把右子树挂过去」的原地拼接，可避免递归栈。
