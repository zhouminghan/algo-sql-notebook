为什么用这个思路？
把数组向右轮转 k 位，等价于「整体反转 → 前 k 个反转 → 后 n-k 个反转」三步，原地 O(1) 空间。k 要先对 n 取模。

题目描述

给定整数数组，将数组中的元素向右轮转 k 个位置。

示例：
nums=[1,2,3,4,5,6,7], k=3 → [5,6,7,1,2,3,4]

图解即思路

① 整体反转 [7,6,5,4,3,2,1]
② 前 k=3 个反转 → [5,6,7,...]
③ 后 n-k 个反转 → [5,6,7,1,2,3,4]
结论
三次反转组合出「循环右移」效果，且完全原地。

最优解代码

Python

def rotate(nums, k):
    n = len(nums)
    k %= n
    def rev(l, r):
        while l < r:
            nums[l], nums[r] = nums[r], nums[l]
            l += 1; r -= 1
    rev(0, n - 1)        # 整体
    rev(0, k - 1)        # 前 k
    rev(k, n - 1)        # 后 n-k

Java

public void rotate(int[] nums, int k) {
    int n = nums.length; k %= n;
    rev(nums, 0, n - 1);
    rev(nums, 0, k - 1);
    rev(nums, k, n - 1);
}
void rev(int[] a, int l, int r) {
    while (l < r) { int t = a[l]; a[l] = a[r]; a[r] = t; l++; r--; }
}

复杂度分析

  • 时间：O(n)
  • 空间：O(1)

易错点

  • k 取模：k 可能大于 n，先 k %= n，否则反转区间越界
  • 三步顺序：先整体、再前 k、再后 n-k，顺序不能乱
自我检验

Q: k=0 或 k=n？

答： k%=n 后为 0，三次反转互相抵消，数组不变。

Q: 左轮转怎么做？

答： 同理先整体反转，再反转「前 n-k」和「后 k」即可。
