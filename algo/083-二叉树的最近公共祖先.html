为什么用这个思路？
自底向上递归：若当前节点是 p 或 q 就返回它；否则看左右子树是否各找到一个。两边都找到 → 当前就是 LCA；只一边找到 → 返回那一边。

题目描述

给定二叉树，找到该树中两个指定节点的最近公共祖先（LCA）。

示例：
树 [3,5,1,6,2,0,8,null,null,7,4]，p=5, q=1 → 3；p=5, q=4 → 5

图解即思路

① 自底向上：左右各找到一个，当前即 LCA
② 只一边找到，继续上抛
结论
递归返回「找到的 p/q 或 LCA」，两边会师处就是最近公共祖先。

最优解代码

Python

def lowestCommonAncestor(root, p, q):
    if not root or root == p or root == q:
        return root
    left = lowestCommonAncestor(root.left, p, q)
    right = lowestCommonAncestor(root.right, p, q)
    if left and right:
        return root
    return left or right

Java

public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode l = lowestCommonAncestor(root.left, p, q);
    TreeNode r = lowestCommonAncestor(root.right, p, q);
    if (l != null && r != null) return root;
    return l != null ? l : r;
}

复杂度分析

  • 时间：O(n)
  • 空间：O(h)

易错点

  • 返回条件：root 为 p 或 q 直接返回，意味着「找到了」向上传递
  • 两边会师：left 和 right 都非空时当前节点就是 LCA
自我检验

Q: p 是 q 的祖先？

答： 递归到 p 直接返回 p，上层继续上抛 p，结果正确。

Q: p、q 都在同一侧？

答： 只有那一侧返回值非空，继续上抛，直到某一层两侧都命中。
