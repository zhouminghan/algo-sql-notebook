为什么用这个思路？
数组元素在 [1,n] 且只有一个重复，把「下标 i → nums[i]」看成链表的 next 指针，重复数就是环的入口。用环形链表 II 的快慢指针求解，O(n) O(1)。

题目描述

给定包含 n+1 个整数的数组，数字都在 [1,n] 范围内，其中只有一个数字重复出现（可能重复多次）。找出这个重复数。要求不修改数组、O(1) 额外空间。

示例：
[1,3,4,2,2] → 2；[3,1,3,4,2] → 3

图解即思路

① 把 i → nums[i] 当链表 next，重复数即环入口
② 快慢指针找相遇点
③ 从头同速再走，相遇即重复数 2
结论
值域 [1,n] 保证 next 不出界且必有环，环入口就是重复数。

最优解代码

Python

def findDuplicate(nums):
    slow = fast = nums[0]
    while True:
        slow = nums[slow]
        fast = nums[nums[fast]]
        if slow == fast:
            break
    p = nums[0]
    while p != slow:
        p = nums[p]
        slow = nums[slow]
    return p

Java

public int findDuplicate(int[] nums) {
    int slow = nums[0], fast = nums[0];
    do {
        slow = nums[slow];
        fast = nums[nums[fast]];
    } while (slow != fast);
    int p = nums[0];
    while (p != slow) { p = nums[p]; slow = nums[slow]; }
    return p;
}

复杂度分析

  • 时间：O(n)
  • 空间：O(1)

易错点

  • next 用 nums 本身：slow = nums[slow]，fast = nums[nums[fast]]，别直接下标加减
  • 入口即答案：环入口是重复数，因为只有重复数被多个节点指向
自我检验

Q: 为什么必有环？

答： n+1 个值落在 [1,n]，鸽巢原理必有重复；从下标 0 出发的 next 链最终进入由重复数构成的环。

Q: 二分法怎么做？

答： 统计 ≤mid 的个数，若大于 mid 说明重复在左半，O(n log n)，也能 O(1) 空间。
