为什么用这个思路？
翻转 = 对每个节点交换左右子树。递归先交换当前节点左右孩子，再递归翻转左右子树；或先递归再交换都可。

题目描述

给定二叉树根节点，翻转这棵二叉树，返回其根节点（镜像）。

示例：
[4,2,7,1,3,6,9] → [4,7,2,9,6,3,1]

图解即思路

① 原树
② 交换每个节点的左右子树
结论
每个节点做一次左右交换，递归到整棵树。

最优解代码

Python

def invertTree(root):
    if not root:
        return None
    root.left, root.right = root.right, root.left
    invertTree(root.left)
    invertTree(root.right)
    return root

Java

public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    TreeNode t = root.left;
    root.left = root.right;
    root.right = t;
    invertTree(root.left);
    invertTree(root.right);
    return root;
}

复杂度分析

  • 时间：O(n)
  • 空间：O(h)

易错点

  • 先交换再递归：交换当前节点后，左右子树位置已变，递归顺序仍各走一遍即可
  • 空树：root 为 None 直接返回
自我检验

Q: 迭代做法？

答： 用队列做 BFS，每取出一个节点就交换其左右孩子。

Q: 翻转两次？

答： 翻转两次回到原树，翻转是自身的逆操作。
