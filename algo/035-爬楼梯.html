为什么用这个思路？
到第 n 阶，最后一步要么跨 1 阶、要么跨 2 阶，所以 f(n) = f(n-1) + f(n-2)，就是斐波那契数列。用两个变量滚动即可 O(1) 空间。

题目描述

假设你正在爬楼梯，需要 n 阶到达楼顶。每次可以爬 1 或 2 个台阶，问有多少种不同方法爬到楼顶。

示例：
n=2 → 2（1+1、2）；n=3 → 3（1+1+1、1+2、2+1）

图解即思路

① 递推：f(n)=f(n-1)+f(n-2)
② 第 n 阶来自「跨 1」或「跨 2」两种来路
结论
斐波那契数列，滚动两个变量不断前移。

最优解代码

Python

def climbStairs(n):
    a, b = 1, 1
    for _ in range(n):
        a, b = b, a + b
    return a

Java

public int climbStairs(int n) {
    int a = 1, b = 1;
    for (int i = 0; i < n; i++) {
        int t = a + b;
        a = b; b = t;
    }
    return a;
}

复杂度分析

  • 时间：O(n)
  • 空间：O(1)

易错点

  • 边界 f(0)=1：把 f(0) 定义为 1 能让递推统一，n=1 返回 1
  • 别用朴素递归：朴素递归是指数级；记忆化或迭代才是线性
自我检验

Q: n=0 或 n=1？

答： 约定 f(0)=1、f(1)=1，代码里 a 初始 1 直接覆盖。

Q: 如果一次能爬 1~3 阶呢？

答： 递推改为 f(n)=f(n-1)+f(n-2)+f(n-3)，滚动维护三个变量即可。
