为什么用这个思路？
凑出金额 i 的最少硬币数 dp[i] = min(dp[i - coin]) + 1。完全背包模型，硬币可无限用，逐金额填表，无法凑出则 -1。

题目描述

给定不同面额的硬币 coins 和一个总金额 amount，计算凑出该金额所需的最少硬币个数。无解返回 -1。

示例：
coins=[1,2,5], amount=11 → 3（5+5+1）；coins=[2], amount=3 → -1

图解即思路

① dp[i] = min(dp[i-coin]) + 1
② amount=11：11-5=6(dp=2)、11-2=9(dp=3)、11-1=10(dp=2)，min=2+1=3
结论
每种硬币都试一遍，取「剩余金额最优 + 1」的最小值。

最优解代码

Python

def coinChange(coins, amount):
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    for i in range(1, amount + 1):
        for c in coins:
            if i >= c:
                dp[i] = min(dp[i], dp[i - c] + 1)
    return dp[amount] if dp[amount] != float('inf') else -1

Java

public int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);
    dp[0] = 0;
    for (int i = 1; i <= amount; i++)
        for (int c : coins)
            if (i >= c) dp[i] = Math.min(dp[i], dp[i - c] + 1);
    return dp[amount] > amount ? -1 : dp[amount];
}

复杂度分析

  • 时间：O(amount · len(coins))
  • 空间：O(amount)

易错点

  • 无解返回 -1：用 amount+1 或 inf 初始化，最后判断是否被更新
  • 硬币可重复使用：内层是金额循环，每个金额重新遍历所有硬币，等价完全背包
自我检验

Q: coins=[2], amount=3？

答： dp[3] 一直无法更新（3-2=1 无解），返回 -1。

Q: 最少个数 vs 组合总数？

答： 本题求最少（取 min）；组合总数是另一个经典 DP，求累加和。
