🤔 为什么用这个思路？
每行首尾是 1，中间每个数 = 上一行相邻两数之和。逐行生成即可，是典型的递推填表。

📄 题目描述

给定非负整数 numRows，生成杨辉三角的前 numRows 行。杨辉三角中每个数是它左上方和右上方的数之和。

示例：
numRows=5 → [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]

📐 图解即思路

① 每行首尾 1，中间 = 左上 + 右上
② 递推：cur[j] = prev[j-1] + prev[j]
✅ 结论
一行一行填，中间元素由上一行相邻两项相加得到。

📝 最优解代码

Python

def generate(numRows):
    res = []
    for i in range(numRows):
        row = [1] * (i + 1)
        for j in range(1, i):
            row[j] = res[-1][j - 1] + res[-1][j]
        res.append(row)
    return res

Java

public List<List<Integer>> generate(int numRows) {
    List<List<Integer>> res = new ArrayList<>();
    for (int i = 0; i < numRows; i++) {
        List<Integer> row = new ArrayList<>();
        for (int j = 0; j <= i; j++) {
            if (j == 0 || j == i) row.add(1);
            else row.add(res.get(i - 1).get(j - 1) + res.get(i - 1).get(j));
        }
        res.add(row);
    }
    return res;
}

⏱ 复杂度分析

  • 时间：O(numRows²)
  • 空间：O(numRows²) — 结果本身

⚠️ 易错点

  • 首尾处理：j==0 或 j==i 时固定为 1，中间才相加
  • 用上一行：本行依赖 res[-1]，确保上一行已生成
🧪 自我检验

Q: numRows=0？

✅ 答： 返回空列表。

Q: 第 n 行第 k 个数与组合数的关系？

✅ 答： 等于 C(n,k)，杨辉三角本质就是二项式系数的递推。
