为什么用这个思路？
正着戳会改变邻居、子问题不独立。反过来：设 dp[i][j] 为「开区间 (i,j) 内能得到的最大硬币」，枚举最后戳的气球 k，dp[i][j] = max(dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j])。

题目描述

有 n 个气球排成一排，每个气球上有数字 nums[i]。戳破第 i 个气球可得 nums[i-1] * nums[i] * nums[i+1] 枚硬币（越界处视为 1）。求最多硬币数。

示例：
[3,1,5,8] → 167（1→5→3→8 顺序）

图解即思路

① 两端补 1，dp[i][j] 为开区间 (i,j) 最大硬币
② 枚举最后戳 k：dp[i][j]=dp[i][k]+dp[k][j]+nums[i]*nums[k]*nums[j]
③ 按区间长度递增填表，答案 dp[0][n+1]
结论
把「最后戳谁」当决策点，两侧区间互不影响，区间 DP 经典模型。

最优解代码

Python

def maxCoins(nums):
    nums = [1] + nums + [1]
    n = len(nums)
    dp = [[0] * n for _ in range(n)]
    for length in range(3, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            for k in range(i + 1, j):
                dp[i][j] = max(dp[i][j], dp[i][k] + dp[k][j] + nums[i] * nums[k] * nums[j])
    return dp[0][n - 1]

Java

public int maxCoins(int[] nums) {
    int m = nums.length;
    int[] a = new int[m + 2];
    a[0] = a[m + 1] = 1;
    System.arraycopy(nums, 0, a, 1, m);
    int n = m + 2;
    int[][] dp = new int[n][n];
    for (int len = 3; len <= n; len++)
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            for (int k = i + 1; k < j; k++)
                dp[i][j] = Math.max(dp[i][j], dp[i][k] + dp[k][j] + a[i] * a[k] * a[j]);
        }
    return dp[0][n - 1];
}

复杂度分析

  • 时间：O(n³)
  • 空间：O(n²)

易错点

  • 枚举「最后戳」而非「第一个戳」：戳第一个会改变两侧邻居，子问题耦合；最后戳则两侧已固定为 i、j
  • 两端补 1：越界视为 1，补 1 后公式统一
自我检验

Q: 为什么区间长度从 3 开始？

答： 开区间 (i,j) 至少要有中间一个气球 k，即 j-i≥2。

Q: 回溯思路 vs 正着贪心？

答： 贪心不行；区间 DP 把「最后戳谁」作为划分，保证子问题独立。
