🤔 为什么用这个思路？
从每个格子出发做 DFS，向上下左右四个方向匹配单词的下一字符；走过的格子暂时标记，走不通就回溯还原，避免重复使用同一格。

📄 题目描述

给定 m×n 的字符网格 board 和字符串 word，判断 word 是否存在于网格中。单词必须按相邻单元格的字母构成（水平或垂直相邻），同一单元格不能用两次。

示例：
board=[["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word="ABCCED" → true

📐 图解即思路

① 从每个格子出发，向四周 DFS
② 匹配路径 A→B→C→C→E→D，走过的格子临时标记
③ 走不通就回溯，恢复标记，换方向
✅ 结论
四个方向递归匹配 + 原地标记去重 + 失败回溯，遍历所有起点即可判断是否存在。

📝 最优解代码

Python

def exist(board, word):
    m, n = len(board), len(board[0])
    def dfs(i, j, k):
        if k == len(word):
            return True
        if i < 0 or i >= m or j < 0 or j >= n or board[i][j] != word[k]:
            return False
        tmp = board[i][j]
        board[i][j] = '#'          # 标记已走
        found = (dfs(i + 1, j, k + 1) or dfs(i - 1, j, k + 1)
                 or dfs(i, j + 1, k + 1) or dfs(i, j - 1, k + 1))
        board[i][j] = tmp          # 回溯还原
        return found
    for i in range(m):
        for j in range(n):
            if dfs(i, j, 0):
                return True
    return False

Java

public boolean exist(char[][] board, String word) {
    int m = board.length, n = board[0].length;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (dfs(board, word, i, j, 0)) return true;
    return false;
}
boolean dfs(char[][] b, String w, int i, int j, int k) {
    if (k == w.length()) return true;
    if (i < 0 || i >= b.length || j < 0 || j >= b[0].length || b[i][j] != w.charAt(k)) return false;
    char tmp = b[i][j]; b[i][j] = '#';
    boolean f = dfs(b, w, i + 1, j, k + 1) || dfs(b, w, i - 1, j, k + 1)
             || dfs(b, w, i, j + 1, k + 1) || dfs(b, w, i, j - 1, k + 1);
    b[i][j] = tmp;
    return f;
}

⏱ 复杂度分析

  • 时间：O(m·n·3^L) — L 为单词长度，每步最多 3 个方向
  • 空间：O(L) — 递归深度

⚠️ 易错点

  • 标记与还原：用 board[i][j]='#' 临时占用，返回前必须还原，否则兄弟分支被污染
  • 方向边界：四个方向都要判越界，别漏 i、j 的范围检查
🧪 自我检验

Q: 同一格子能用两次吗？

✅ 答： 不能。标记 '#' 后，后续递归不会再匹配它，回溯时再还原给别的路径使用。

Q: 多个起点怎么处理？

✅ 答： 外层双重循环对每个格子都尝试作为起点，只要有一个返回 true 即存在。
