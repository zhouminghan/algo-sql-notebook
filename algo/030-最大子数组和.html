🤔 为什么用这个思路？
Kadane 算法：以 i 结尾的最大子数组和，要么接着前面的（pre + x），要么另起炉灶（x）。每步取较大者，同时更新全局最大，一次遍历 O(n)。

📄 题目描述

给定一个整数数组，找出一个具有最大和的连续子数组，返回其最大和。

示例：
[-2,1,-3,4,-1,2,1,-5,4] → 6（子数组 [4,-1,2,1]）

📐 图解即思路

① 到 i 为止：接前面 or 另起
② 递推：dp[i] = max(dp[i-1]+x, x)
③ 全局最大 = max(dp) = 6
✅ 结论
「当前子数组和」一旦变负就果断丢弃、重新开始，过程中记录到的最大值就是答案。

📝 最优解代码

Python

def maxSubArray(nums):
    cur = ans = nums[0]
    for x in nums[1:]:
        cur = max(cur + x, x)   # 接前面 或 另起
        ans = max(ans, cur)
    return ans

Java

public int maxSubArray(int[] nums) {
    int cur = nums[0], ans = nums[0];
    for (int i = 1; i < nums.length; i++) {
        cur = Math.max(cur + nums[i], nums[i]);
        ans = Math.max(ans, cur);
    }
    return ans;
}

⏱ 复杂度分析

  • 时间：O(n) — 一次遍历
  • 空间：O(1) — 只维护两个变量

⚠️ 易错点

  • 全负数组：cur 初始化为 nums[0] 并逐个比较，仍能返回最大的那个负数
  • cur 变负要丢弃：cur+x < x 时说明前面是累赘，应另起炉灶，这是 Kadane 的核心
🧪 自我检验

Q: 全负数组 [-2,-3,-1] 答案？

✅ 答： -1。每步 cur 都会重置为当前更大的值，ans 保持 -1。

Q: 需要记录子数组下标吗？

✅ 答： 本题只求最大和；若要下标，可在 cur 重置时记录起点，更新 ans 时记录终点。
