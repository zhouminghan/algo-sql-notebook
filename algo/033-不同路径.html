为什么用这个思路？
到达每个格子只能「从上边来」或「从左边来」，所以 dp[i][j] = dp[i-1][j] + dp[i][j-1]。第一行第一列恒为 1。这是最经典的二维 DP 入门。

题目描述

一个机器人位于 m×n 网格的左上角，每次只能向下或向右移动一步，问到达右下角共有多少条不同路径。

示例：
m=3, n=7 → 28；m=3, n=2 → 3

图解即思路

① 第一行第一列都只有 1 条路径
② dp[i][j] = dp[i-1][j] + dp[i][j-1]
结论
逐格填表，右下角的值就是总路径数。

最优解代码

Python

def uniquePaths(m, n):
    dp = [[1] * n for _ in range(m)]
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
    return dp[-1][-1]

Java

public int uniquePaths(int m, int n) {
    int[][] dp = new int[m][n];
    for (int i = 0; i < m; i++) dp[i][0] = 1;
    for (int j = 0; j < n; j++) dp[0][j] = 1;
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
    return dp[m - 1][n - 1];
}

复杂度分析

  • 时间：O(m · n)
  • 空间：O(m · n) — 可滚动数组优化到 O(n)

易错点

  • 初始化边界：第一行与第一列全是 1，不能漏
  • 递推方向：只能从左上到右下，保证 dp[i-1][j]、dp[i][j-1] 已算好
自我检验

Q: m=1 或 n=1？

答： 只有一行或一列时只有一条路径，返回 1，初始化已覆盖。

Q: 如何优化空间？

答： dp 只依赖上一行和当前行左侧，用一维数组 dp[j] += dp[j-1] 即可 O(n) 空间。
