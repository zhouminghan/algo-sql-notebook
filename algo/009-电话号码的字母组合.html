009

电话号码的字母组合

中等 回溯 哈希表
→ LeetCode 原题
🤔 为什么用回溯？
每个数字映射 3-4 个字母，组合总数最多 4ⁿ。回溯递归地构建每个组合，到达叶子节点（长度等于 digits 长度）时收集结果。

📄 题目描述

给定一个仅包含数字 2-9 的字符串，返回所有它能表示的字母组合。数字到字母的映射与电话按键相同。

示例：

输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]

📐 图解即思路

🌳 回溯树
每个数字对应一个字母集合。DFS 遍历：从第 0 个数字开始，依次取每个字母加入 path，递归处理下一个数字。到达末尾时 path 即为一个有效组合。
① digits="23": 数字2→[a,b,c], 数字3→[d,e,f]
② 选 'a' → 递归到数字3，依次选 d/e/f → ad,ae,af
③ 回溯，选 'b' → 递归 → bd,be,bf
④ 回溯，选 'c' → 递归 → cd,ce,cf，收集全部 9 种组合
✅ 结论
回溯模板：for 每个选择 → 做选择 → 递归 → 撤销选择。时间 O(4ⁿ)，空间 O(n) 递归栈深度。

📝 最优解代码

Python

def letterCombinations(digits: str):
    if not digits:
        return []

    phone = {
        '2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
        '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz'
    }
    res = []

    def backtrack(idx, path):
        if idx == len(digits):
            res.append(''.join(path))
            return
        for ch in phone[digits[idx]]:
            path.append(ch)
            backtrack(idx + 1, path)
            path.pop()

    backtrack(0, [])
    return res

Java

public List<String> letterCombinations(String digits) {
    if (digits.isEmpty()) return new ArrayList<>();
    String[] phone = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
    List<String> res = new ArrayList<>();
    backtrack(digits, 0, new StringBuilder(), phone, res);
    return res;
}

private void backtrack(String digits, int idx, StringBuilder path, String[] phone, List<String> res) {
    if (idx == digits.length()) {
        res.add(path.toString());
        return;
    }
    for (char c : phone[digits.charAt(idx) - '0'].toCharArray()) {
        path.append(c);
        backtrack(digits, idx + 1, path, phone, res);
        path.deleteCharAt(path.length() - 1);
    }
}

⏱ 复杂度分析

  • 时间：O(4ⁿ) — 每个数字最多 4 种选择，共 n 个数字
  • 空间：O(n) — 递归栈深度

⚠️ 易错点

  • 空输入处理：digits="" 时返回 [] 而非 [""]
  • 回溯撤销：path.pop() 或 deleteCharAt() 必须在递归后执行，否则污染后续分支
🧪 自我检验

Q1: digits="2"，输出是什么？

✅ 答：["a","b","c"]。 只有一个数字，每个字母构成一个单字符组合。

Q2: 能否用迭代（队列）代替递归？

✅ 答：可以。 初始化队列=[""]，遍历每个数字，将队列中每个元素拼接当前数字的所有字母后重新入队。时间相同，但需要额外空间存储中间结果。
