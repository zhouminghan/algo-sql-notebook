为什么用这个思路？
每个数字对应几个字母，组合就是「每个位置选一个字母」的决策树。回溯逐位枚举，到底收集一个组合，再撤销换下一个。

题目描述

给定仅含数字 2-9 的字符串，返回它能表示的所有字母组合。数字到字母的映射与电话按键相同。

示例：
"23" → ["ad","ae","af","bd","be","bf","cd","ce","cf"]

图解即思路

① 数字到字母的映射
② 决策树：每位选一个字母
③ 3×3=9 种组合
结论
每位枚举字母，深度等于数字个数，到底即收集。

最优解代码

Python

def letterCombinations(digits):
    if not digits:
        return []
    mp = {'2':'abc','3':'def','4':'ghi','5':'jkl','6':'mno','7':'pqrs','8':'tuv','9':'wxyz'}
    ans = []
    def dfs(i, path):
        if i == len(digits):
            ans.append(''.join(path)); return
        for ch in mp[digits[i]]:
            path.append(ch)
            dfs(i + 1, path)
            path.pop()
    dfs(0, [])
    return ans

Java

public List<String> letterCombinations(String digits) {
    if (digits.isEmpty()) return new ArrayList<>();
    String[] mp = {"","","abc","def","ghi","jkl","mno","pqrs","tuv","wxyz"};
    List<String> ans = new ArrayList<>();
    dfs(digits, 0, new StringBuilder(), mp, ans);
    return ans;
}
void dfs(String d, int i, StringBuilder sb, String[] mp, List<String> ans) {
    if (i == d.length()) { ans.add(sb.toString()); return; }
    for (char c : mp[d.charAt(i) - '0'].toCharArray()) {
        sb.append(c); dfs(d, i + 1, sb, mp, ans); sb.deleteCharAt(sb.length() - 1);
    }
}

复杂度分析

  • 时间：O(3^m·4^n) — 组合数级别
  • 空间：O(组合数长度)

易错点

  • 空串返回 []：digits 为空直接返回空列表，不能返回 [""]
  • 回溯撤销：path.append 后要 pop，否则路径串到别的分支
自我检验

Q: "23" 为什么是 9 种？

答： 2 有 3 个字母、3 有 3 个字母，3×3=9。

Q: 7 和 9 有几个字母？

答： 都是 4 个（pqrs / wxyz），其余是 3 个。
