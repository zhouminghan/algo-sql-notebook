🤔 为什么用快慢指针？
单链表无法从后往前数。快指针先走 n 步，然后快慢同步走，快指针到末尾时慢指针正好在倒数第 n 个节点的前驱。一趟扫描 O(n)。

📄 题目描述

给你一个链表，删除链表的倒数第 n 个结点，并且返回链表的头结点。

示例：

输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
解释：删除倒数第 2 个节点（值为 4）

📐 图解即思路

🏃 快慢指针
使用 dummy 头节点简化删除头节点的边界情况。fast 先走 n+1 步（到待删节点的后一个），然后 fast/slow 同步走，fast 到 null 时 slow 指向待删节点的前驱。
① 初始：dummy→1→2→3→4→5, n=2
② fast 先走 n+1=3 步，到达节点 3
③ fast/slow 同步走，fast 到 null 时 slow 指向 3
④ 删除 slow.next(4)：slow.next = slow.next.next → 1→2→3→5
✅ 结论
dummy 节点统一处理（包括删除头节点）。fast 先走 n+1 步确保 slow 指向待删节点的前驱。O(n) 时间，O(1) 空间。

📝 最优解代码

Python

def removeNthFromEnd(head, n):
    dummy = ListNode(0, head)
    fast = slow = dummy

    for _ in range(n + 1):
        fast = fast.next

    while fast:
        fast = fast.next
        slow = slow.next

    slow.next = slow.next.next
    return dummy.next

Java

public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0, head);
    ListNode fast = dummy, slow = dummy;

    for (int i = 0; i <= n; i++) {
        fast = fast.next;
    }

    while (fast != null) {
        fast = fast.next;
        slow = slow.next;
    }

    slow.next = slow.next.next;
    return dummy.next;
}

⏱ 复杂度分析

  • 时间：O(L) — 一趟扫描，L 为链表长度
  • 空间：O(1)

⚠️ 易错点

  • dummy 节点必须：删除头节点时需要前驱，dummy 统一处理所有情况
  • fast 走 n+1 步：多走 1 步使 slow 指向待删节点的前驱，方便删除操作
🧪 自我检验

Q1: head=[1], n=1，删除后是什么？

✅ 答：[]。 dummy→1，fast 走 2 步到 null，slow/fast 同步走（fast 已是 null 循环不执行），slow 指向 dummy，slow.next.next=null，返回 dummy.next=null。

Q2: 为什么 fast 要先走 n+1 步而不是 n 步？

✅ 答：让 slow 指向待删节点的前驱。 如果 fast 只走 n 步，同步走到末尾时 slow 正好指向待删节点本身，无法删除（单链表需要前驱）。多走 1 步让 slow 落后一个位置。
