为什么用这个思路？
每个元素有「选 / 不选」两种选择，子集共有 2^n 个。回溯按「从当前下标往后选」遍历，每进入一层就先把当前组合记下，就能无遗漏地收集所有子集。

题目描述

给定一个不含重复元素的整数数组 nums，返回该数组所有可能的子集（幂集）。

示例：
nums=[1,2,3] → [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

图解即思路

① 每个元素「选 / 不选」的决策树
② 每进入一层，当前 path 就是一个子集，立即收集
结论
「进入即收集」保证从空集到全集每个中间状态都不漏。

最优解代码

Python

def subsets(nums):
    ans = []
    def dfs(start, path):
        ans.append(path[:])        # 每个状态都是子集
        for i in range(start, len(nums)):
            path.append(nums[i])
            dfs(i + 1, path)       # 不重复：只往后选
            path.pop()
    dfs(0, [])
    return ans

Java

public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> ans = new ArrayList<>();
    dfs(nums, 0, new ArrayList<>(), ans);
    return ans;
}
void dfs(int[] nums, int start, List<Integer> path, List<List<Integer>> ans) {
    ans.add(new ArrayList<>(path));
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);
        dfs(nums, i + 1, path, ans);
        path.remove(path.size() - 1);
    }
}

复杂度分析

  • 时间：O(n · 2^n) — 2^n 个子集，每个复制一次
  • 空间：O(n) — 递归栈

易错点

  • 进入就收集：不要等到叶子才收集，否则会漏掉中间态（如 [1]、[1,2]）
  • start 下标去重：从 start 往后选保证子集内部有序，避免 [1,2] 与 [2,1] 重复
自我检验

Q: 位运算怎么做这题？

答： 0 到 2^n-1 每个数对应一个子集，第 k 位为 1 表示选 nums[k]，时间 O(n·2^n)。

Q: nums 有重复元素呢？

答： 先排序，循环里跳过「同级重复」元素，避免生成重复子集。
