004

寻找两个正序数组的中位数

困难 二分查找 数组
→ LeetCode 原题
🤔 为什么用二分查找？
合并两数组 O(m+n)，但题目要求 O(log(m+n))。核心思想：在较短数组上二分查找分割线，使得左半部分最大值 ≤ 右半部分最小值，避免真正合并。

📄 题目描述

给定两个大小分别为 m 和 n 的正序数组 nums1 和 nums2。找出这两个正序数组的 中位数，时间复杂度 O(log(m+n))。

示例：

输入：nums1 = [1,3], nums2 = [2]
输出：2.0
解释：合并数组 = [1,2,3]，中位数 2

📐 图解即思路

🔪 分割线思想
在 nums1 上二分查找分割点 i，则 nums2 的分割点 j = (m+n+1)//2 - i。满足 nums1[i-1] ≤ nums2[j] 且 nums2[j-1] ≤ nums1[i] 时找到正确分割。
① nums1=[1,3], nums2=[2], 在 nums1 上二分 i=1
② i=1, j=(3+1)//2-1=1，检查条件
③ nums1[0]=1 ≤ nums2[1]=+∞ ✓, nums2[0]=2 ≤ nums1[1]=3 ✓
④ 奇数长度(m+n=3)：中位数 = max(左半) = max(1,2) = 2
✅ 结论
在较短数组上二分，保证 j 非负。边界用 ±inf 处理。奇数取 max(左半)，偶数取 (max(左半)+min(右半))/2。O(log(min(m,n)))。

📝 最优解代码

Python

def findMedianSortedArrays(nums1, nums2):
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1
    m, n = len(nums1), len(nums2)
    left, right = 0, m
    half = (m + n + 1) // 2

    while left <= right:
        i = (left + right) // 2
        j = half - i
        l1 = nums1[i-1] if i > 0 else float('-inf')
        r1 = nums1[i] if i < m else float('inf')
        l2 = nums2[j-1] if j > 0 else float('-inf')
        r2 = nums2[j] if j < n else float('inf')

        if l1 <= r2 and l2 <= r1:
            if (m + n) % 2 == 1:
                return max(l1, l2)
            return (max(l1, l2) + min(r1, r2)) / 2
        elif l1 > r2:
            right = i - 1
        else:
            left = i + 1
    return 0.0

Java

public double findMedianSortedArrays(int[] nums1, int[] nums2) {
    if (nums1.length > nums2.length) {
        int[] temp = nums1; nums1 = nums2; nums2 = temp;
    }
    int m = nums1.length, n = nums2.length;
    int left = 0, right = m, half = (m + n + 1) / 2;

    while (left <= right) {
        int i = (left + right) / 2;
        int j = half - i;
        double l1 = (i > 0) ? nums1[i-1] : Double.NEGATIVE_INFINITY;
        double r1 = (i < m) ? nums1[i] : Double.POSITIVE_INFINITY;
        double l2 = (j > 0) ? nums2[j-1] : Double.NEGATIVE_INFINITY;
        double r2 = (j < n) ? nums2[j] : Double.POSITIVE_INFINITY;

        if (l1 <= r2 && l2 <= r1) {
            if ((m + n) % 2 == 1) return Math.max(l1, l2);
            return (Math.max(l1, l2) + Math.min(r1, r2)) / 2.0;
        } else if (l1 > r2) {
            right = i - 1;
        } else {
            left = i + 1;
        }
    }
    return 0.0;
}

⏱ 复杂度分析

  • 时间：O(log(min(m, n))) — 在较短数组上二分
  • 空间：O(1)

⚠️ 易错点

  • 保证 nums1 较短：否则 j = half - i 可能为负，导致索引越界
  • 边界条件：i=0 或 i=m 时用 -inf/+inf 代替越界值，避免特殊判断
  • 奇偶长度公式不同：奇数取 max(l1,l2)，偶数取 (max(l1,l2)+min(r1,r2))/2
🧪 自我检验

Q1: nums1=[1,2], nums2=[3,4]，中位数是多少？

✅ 答：2.5。 合并后 [1,2,3,4]，偶数长度，(2+3)/2=2.5。i=1, j=1，l1=1, r1=2, l2=3, r2=4，满足条件，中位数=(max(1,3)+min(2,4))/2=2.5。

Q2: 为什么要在较短数组上二分？

✅ 答：保证 j 非负。 j = half - i，half = (m+n+1)//2。若 nums1 较长且 i 取 m，j = half - m。由于 m > half 时 j 为负。在较短数组上二分，i ∈ [0, m] ≤ half，j 始终 ≥ 0。
