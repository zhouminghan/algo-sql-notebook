为什么用这个思路？
以 i 为根时，左子树有 i-1 个节点、右子树有 n-i 个节点，数量相乘再对 i 求和，即卡特兰数递推：G(n)=Σ G(i-1)·G(n-i)。

题目描述

给定整数 n，求由 n 个节点组成且节点值从 1 到 n 互不相同的二叉搜索树有多少种。

示例：
n=3 → 5

图解即思路

① 以 i 为根：左子树 G(i-1) 种 × 右子树 G(n-i) 种
② 卡特兰数：G(0)=1, G(1)=1, G(2)=2, G(3)=5
结论
枚举根节点，左右子树数量相乘累加，DP 递推得到卡特兰数。

最优解代码

Python

def numTrees(n):
    dp = [0] * (n + 1)
    dp[0] = dp[1] = 1
    for i in range(2, n + 1):
        for j in range(1, i + 1):
            dp[i] += dp[j - 1] * dp[i - j]
    return dp[n]

Java

public int numTrees(int n) {
    int[] dp = new int[n + 1];
    dp[0] = dp[1] = 1;
    for (int i = 2; i <= n; i++)
        for (int j = 1; j <= i; j++)
            dp[i] += dp[j - 1] * dp[i - j];
    return dp[n];
}

复杂度分析

  • 时间：O(n²)
  • 空间：O(n)

易错点

  • G(0)=1：空树算一种，边界定义成 1 递推才成立
  • 累加不是相乘整体：每个根 j 贡献 dp[j-1]*dp[i-j]，要累加所有 j
自我检验

Q: n=2 为什么是 2？

答： 以 1 为根：右子树 G(1)=1；以 2 为根：左子树 G(1)=1；合计 2。

Q: 这题与「生成所有 BST」区别？

答： 本题只数个数（DP/卡特兰数）；生成所有 BST 需要递归构造左右子树并组合。
