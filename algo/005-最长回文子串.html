🤔 为什么用中心扩展法？
DP 和中心扩展都是 O(n²)，但中心扩展 O(1) 空间且更直观。每个字符作为中心向两边扩展，分奇偶两种情况。

📄 题目描述

给你一个字符串 s，找到 s 中最长的回文子串。

示例：

输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案

📐 图解即思路

🎯 中心扩展法
遍历每个字符作为回文中心，分别以单字符（奇数回文）和双字符（偶数回文）为中心向两边扩展，记录最长回文子串的起止位置。
① 以 s[0]='b' 为中心（奇数） → "b"，长度 1
② 以 s[1]='a' 为中心扩展 → s[0]=s[2]='b' → "bab"，长度 3
③ 以 s[2]='b' 为中心扩展 → s[1]=s[3]='a' → "aba"，长度 3
④ 以 s[2]='b' 和 s[3]='a' 为中心（偶数） → 'b'≠'a' 不回文
⑤ 最终结果：最长回文子串 "bab" 或 "aba"，长度 3
✅ 结论
中心扩展法 O(n²) 时间、O(1) 空间。每个位置检查奇数和偶数两种扩展方式，记录最长结果。比 DP 更省空间。

📝 最优解代码

Python

def longestPalindrome(s: str) -> str:
    n = len(s)
    start, max_len = 0, 1

    def expand(l, r):
        while l >= 0 and r < n and s[l] == s[r]:
            l -= 1; r += 1
        return l + 1, r - 1

    for i in range(n):
        # 奇数长度回文
        l, r = expand(i, i)
        if r - l + 1 > max_len:
            start, max_len = l, r - l + 1
        # 偶数长度回文
        l, r = expand(i, i + 1)
        if r - l + 1 > max_len:
            start, max_len = l, r - l + 1

    return s[start:start + max_len]

Java

public String longestPalindrome(String s) {
    int n = s.length();
    int start = 0, maxLen = 1;

    for (int i = 0; i < n; i++) {
        // 奇数长度
        int[] odd = expand(s, i, i);
        if (odd[1] - odd[0] + 1 > maxLen) {
            start = odd[0]; maxLen = odd[1] - odd[0] + 1;
        }
        // 偶数长度
        int[] even = expand(s, i, i + 1);
        if (even[1] - even[0] + 1 > maxLen) {
            start = even[0]; maxLen = even[1] - even[0] + 1;
        }
    }
    return s.substring(start, start + maxLen);
}

private int[] expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
        l--; r++;
    }
    return new int[]{l + 1, r - 1};
}

⏱ 复杂度分析

  • 时间：O(n²) — 每个字符向两边扩展最坏 O(n)
  • 空间：O(1) — 只用几个变量

⚠️ 易错点

  • 区分奇偶扩展：奇数从 (i,i) 开始，偶数从 (i,i+1) 开始，两种都要检查
  • expand 返回值：while 循环会在不满足条件时多走一步，返回时需要回退 (l+1, r-1)
🧪 自我检验

Q1: s = "cbbd"，最长回文子串是什么？

✅ 答："bb"。 奇数扩展全部为单字符（长度 1）。偶数扩展中，以 (1,2)="bb" 为中心扩展到 "bb"，长度 2。所以答案是 "bb"。

Q2: 中心扩展和 DP 解法比较？

✅ 答：时间都是 O(n²)。 DP 用 dp[i][j] 表示 s[i..j] 是否回文，需要 O(n²) 空间。中心扩展 O(1) 空间，代码更简洁。面试推荐中心扩展法。
