🤔 为什么用 DP？
匹配问题天然有子结构：s[0..i] 是否匹配 p[0..j] 取决于更短的子串匹配结果。* 可以匹配零次或多次前一个字符，产生分支选择。DP 表 O(mn) 穷举所有子问题。

📄 题目描述

给你一个字符串 s 和一个字符规律 p，请你来实现一个支持 '.' 和 '*' 的正则表达式匹配。

  • '.' 匹配任意单个字符
  • '*' 匹配零个或多个前面的那一个元素

示例：

输入：s = "aab", p = "c*a*b"
输出：true
解释：'c' 出现 0 次，'a' 出现 2 次，'b' 匹配

📐 图解即思路

📊 DP 填表
dp[i][j] = s 的前 i 个字符 与 p 的前 j 个字符是否匹配。
- 普通字符 / '.'：dp[i][j] = dp[i-1][j-1]（字符匹配）
- '*'：看前一个字符 x，匹配 0 次 dp[i][j] = dp[i][j-2]，或匹配 ≥1 次 dp[i][j] = dp[i-1][j]（当 x 匹配 s[i-1]）
① 初始化：dp[0][0]=true，空串可匹配空模式
② 处理 p 中 '*'：c* 匹配 0 次 → dp[0][2]=true
③ 填表：a* 匹配 'aa' → dp[2][4]=true
④ 最终 dp[3][5]=true：s="aab" 匹配 p="c*a*b"
✅ 结论
DP 表 O(mn) 格，每格 O(1) 转移。'*' 是关键：可以匹配 0 次（跳过）或多次（依赖上一行）。初始化需处理空串与 a*b* 型模式的匹配。

📝 最优解代码

Python

def isMatch(s: str, p: str) -> bool:
    m, n = len(s), len(p)
    dp = [[False] * (n + 1) for _ in range(m + 1)]
    dp[0][0] = True

    # 空串与 a*b* 型模式
    for j in range(2, n + 1):
        if p[j-1] == '*':
            dp[0][j] = dp[0][j-2]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if p[j-1] == '*':
                # 匹配 0 次：跳过 x*
                dp[i][j] = dp[i][j-2]
                # 匹配 1+ 次：x 匹配 s[i-1]
                if p[j-2] == '.' or p[j-2] == s[i-1]:
                    dp[i][j] |= dp[i-1][j]
            elif p[j-1] == '.' or p[j-1] == s[i-1]:
                dp[i][j] = dp[i-1][j-1]

    return dp[m][n]

Java

public boolean isMatch(String s, String p) {
    int m = s.length(), n = p.length();
    boolean[][] dp = new boolean[m+1][n+1];
    dp[0][0] = true;

    for (int j = 2; j <= n; j++) {
        if (p.charAt(j-1) == '*') {
            dp[0][j] = dp[0][j-2];
        }
    }

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            char pc = p.charAt(j-1);
            if (pc == '*') {
                dp[i][j] = dp[i][j-2];
                if (p.charAt(j-2) == '.' || p.charAt(j-2) == s.charAt(i-1)) {
                    dp[i][j] |= dp[i-1][j];
                }
            } else if (pc == '.' || pc == s.charAt(i-1)) {
                dp[i][j] = dp[i-1][j-1];
            }
        }
    }
    return dp[m][n];
}

⏱ 复杂度分析

  • 时间：O(mn) — 填满 DP 表
  • 空间：O(mn) — 可优化到 O(n) 滚动数组

⚠️ 易错点

  • '*' 的两种语义：匹配 0 次 dp[i][j-2]，匹配 1+ 次 dp[i-1][j]，两者取或
  • 初始化空串：dp[0][j] 对 a*b*c* 型模式为 true，需要预先处理
  • 索引偏移：dp[i][j] 对应 s[i-1] 和 p[j-1]，容易搞混
🧪 自我检验

Q1: s="aa", p="a*"，dp 表如何填？

✅ 答：全部为 true。 dp[0][0]=T, dp[0][2]=T（a*匹配0次）。dp[1][1]=T（a匹配a），dp[1][2]=dp[1][0]|dp[0][2]=F|T=T。同理 dp[2][2]=T。最终 true。

Q2: s="ab", p=".*"，为什么匹配？

✅ 答：'.' 匹配任意字符，'*' 重复任意次。 ".*" 等价于 "零个或多个任意字符"，可以匹配任何字符串。dp 表中所有格都为 true。
