为什么用这个思路？
'.' 匹配任意字符，'*' 匹配前一个字符零次或多次。dp[i][j] 表示 s 前 i 个与 p 前 j 个是否匹配，按 p[j-1] 是不是 '*' 分两种情况递推。

题目描述

给定字符串 s 和字符规律 p，实现支持 . 和 * 的正则匹配。. 匹配任意单个字符；* 匹配零个或多个前面的那个元素。

示例：
s="aab", p="c*a*b" → true（c 重复 0 次，a 重复 2 次）

图解即思路

① dp[i][j]：s 前 i 个与 p 前 j 个是否匹配
② p[j-1]=='*'：看前一个字符匹配几次
③ 普通字符/'.'：直接比对
结论
按 '是否 *' 分支递推，右下角 dp[m][n] 即答案。

最优解代码

Python

def isMatch(s, p):
    m, n = len(s), len(p)
    dp = [[False]*(n+1) for _ in range(m+1)]
    dp[0][0] = True
    for j in range(1, n+1):
        if p[j-1] == '*':
            dp[0][j] = dp[0][j-2]
    for i in range(1, m+1):
        for j in range(1, n+1):
            if p[j-1] == '*':
                dp[i][j] = dp[i][j-2] or (dp[i-1][j] and (s[i-1] == p[j-2] or p[j-2] == '.'))
            else:
                dp[i][j] = dp[i-1][j-1] and (s[i-1] == p[j-1] or p[j-1] == '.')
    return dp[m][n]

Java

public boolean isMatch(String s, String p) {
    int m = s.length(), n = p.length();
    boolean[][] dp = new boolean[m+1][n+1];
    dp[0][0] = true;
    for (int j = 1; j <= n; j++) if (p.charAt(j-1) == '*') dp[0][j] = dp[0][j-2];
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++) {
            if (p.charAt(j-1) == '*') {
                dp[i][j] = dp[i][j-2] || (dp[i-1][j] && (s.charAt(i-1) == p.charAt(j-2) || p.charAt(j-2) == '.'));
            } else {
                dp[i][j] = dp[i-1][j-1] && (s.charAt(i-1) == p.charAt(j-1) || p.charAt(j-1) == '.');
            }
        }
    return dp[m][n];
}

复杂度分析

  • 时间：O(m·n)
  • 空间：O(m·n)

易错点

  • dp[0][j] 初始化：s 为空但 p 形如 a*b* 时可能匹配，要单独处理 '前缀'
  • '*' 两个来源：当 0 个（dp[i][j-2]）和当多个（dp[i-1][j]），漏一个会错
自我检验

Q: "aab" 与 "c*a*b" 为何匹配？

答： c* 匹配 0 个 c，a* 匹配 2 个 a，最后 b 匹配 b。

Q: '.*' 匹配什么？

答： 任意字符重复任意次，等价匹配任意字符串。
