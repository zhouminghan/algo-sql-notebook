🤔 为什么用这个思路？
课程依赖构成有向图，能否修完 = 图是否无环（可拓扑排序）。Kahn 算法：统计入度，把入度为 0 的课入队，依次出队并把后续课入度减一；若最终修完所有课则无环。

📄 题目描述

你需要修 numCourses 门课。先修课程 prerequisites[i] = [a, b] 表示修 a 前必须先修 b。判断是否可能完成所有课程。

示例：
numCourses=2, [[1,0]] → true；[[1,0],[0,1]] → false（互相依赖成环）

📐 图解即思路

① 建图并统计入度
② 入度 0 的课入队，出队后把后续课入度 -1
③ 修完的课数 == 总数则无环可完成
✅ 结论
拓扑排序能排完全部课程 = 无环 = 可完成。

📝 最优解代码

Python

from collections import deque
def canFinish(numCourses, prerequisites):
    indeg = [0] * numCourses
    graph = [[] for _ in range(numCourses)]
    for a, b in prerequisites:
        graph[b].append(a)
        indeg[a] += 1
    q = deque([i for i in range(numCourses) if indeg[i] == 0])
    count = 0
    while q:
        cur = q.popleft()
        count += 1
        for nxt in graph[cur]:
            indeg[nxt] -= 1
            if indeg[nxt] == 0:
                q.append(nxt)
    return count == numCourses

Java

public boolean canFinish(int n, int[][] prerequisites) {
    int[] indeg = new int[n];
    List<List<Integer>> g = new ArrayList<>();
    for (int i = 0; i < n; i++) g.add(new ArrayList<>());
    for (int[] p : prerequisites) { g.get(p[1]).add(p[0]); indeg[p[0]]++; }
    Queue<Integer> q = new LinkedList<>();
    for (int i = 0; i < n; i++) if (indeg[i] == 0) q.offer(i);
    int count = 0;
    while (!q.isEmpty()) {
        int cur = q.poll(); count++;
        for (int nxt : g.get(cur)) if (--indeg[nxt] == 0) q.offer(nxt);
    }
    return count == n;
}

⏱ 复杂度分析

  • 时间：O(V + E)
  • 空间：O(V + E) — 邻接表

⚠️ 易错点

  • 边方向：先修 b → 后修 a，建图方向是 b 指向 a，入度记在 a 上
  • 成环判定：最终 count < n 说明有环，返回 false
🧪 自我检验

Q: 为什么拓扑排序能判环？

✅ 答： 无环图才能把所有入度逐步减到 0 并全部出队；有环的节点入度永远降不到 0。

Q: DFS 判环做法？

✅ 答： 三色标记：0 未访问、1 访问中、2 已完成，DFS 遇到「访问中」的节点即发现环。
