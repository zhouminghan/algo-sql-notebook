🤔 为什么用这个思路？
先统计频率，再用大小为 k 的最小堆维护「频率最高的 k 个」：堆满且新频率更高就替换。最后堆里就是答案，时间 O(n log k)。

📄 题目描述

给定整数数组和整数 k，返回出现频率前 k 高的元素。

示例：
[1,1,1,2,2,3], k=2 → [1,2]

📐 图解即思路

① 统计频率
② 维护大小为 k 的最小堆（按频率）
③ 堆中即前 k 高 [1,2]
✅ 结论
最小堆按频率排序，堆顶是「前 k 高里最低的」，低于它的直接淘汰。

📝 最优解代码

Python

import heapq
from collections import Counter
def topKFrequent(nums, k):
    freq = Counter(nums)
    heap = []
    for num, cnt in freq.items():
        heapq.heappush(heap, (cnt, num))
        if len(heap) > k:
            heapq.heappop(heap)
    return [num for cnt, num in heap]

Java

public int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> freq = new HashMap<>();
    for (int x : nums) freq.merge(x, 1, Integer::sum);
    PriorityQueue<Integer> pq = new PriorityQueue<>((a, b) -> freq.get(a) - freq.get(b));
    for (int x : freq.keySet()) {
        pq.offer(x);
        if (pq.size() > k) pq.poll();
    }
    int[] ans = new int[k];
    for (int i = 0; i < k; i++) ans[i] = pq.poll();
    return ans;
}

⏱ 复杂度分析

  • 时间：O(n log k)
  • 空间：O(n)

⚠️ 易错点

  • 堆按频率比较：堆元素是 (cnt, num) 或自定义比较器，别按元素值比较
  • 堆满即弹最小：维护 k 个最高频，弹掉堆顶（频率最低者）
🧪 自我检验

Q: 桶排序做法？

✅ 答： 按频率分桶（下标=频率），从高到低收集，O(n)，适合频率范围小的情况。

Q: 频率相同怎么排序？

✅ 答： 顺序无所谓，题目不要求同频元素的具体次序。
