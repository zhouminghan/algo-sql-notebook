为什么用这个思路？
在字符串上枚举切割点：当前前缀是回文就切下，剩余部分递归分割。用回溯收集所有方案，配合回文预判避免重复判断。

题目描述

给定字符串 s，将 s 分割成若干子串，使每个子串都是回文串。返回所有可能的分割方案。

示例：
s="aab" → [["a","a","b"],["aa","b"]]

图解即思路

① 在每个位置决定「切 / 不切」
② 前缀回文才切下，否则剪枝
结论
枚举每个切点，前缀是回文就继续分割剩余部分，递归到底即得一种方案。

最优解代码

Python

def partition(s):
    n = len(s)
    ans, path = [], []
    def dfs(start):
        if start == n:
            ans.append(path[:]); return
        for end in range(start, n):
            sub = s[start:end + 1]
            if sub == sub[::-1]:       # 前缀回文
                path.append(sub)
                dfs(end + 1)
                path.pop()
    dfs(0)
    return ans

Java

public List<List<String>> partition(String s) {
    List<List<String>> ans = new ArrayList<>();
    dfs(s, 0, new ArrayList<>(), ans);
    return ans;
}
void dfs(String s, int start, List<String> path, List<List<String>> ans) {
    if (start == s.length()) { ans.add(new ArrayList<>(path)); return; }
    for (int end = start; end < s.length(); end++) {
        if (isPal(s, start, end)) {
            path.add(s.substring(start, end + 1));
            dfs(s, end + 1, path, ans);
            path.remove(path.size() - 1);
        }
    }
}
boolean isPal(String s, int l, int r) {
    while (l < r) if (s.charAt(l++) != s.charAt(r--)) return false;
    return true;
}

复杂度分析

  • 时间：O(n · 2^n) — 最坏每个前缀都是回文（如全 a）
  • 空间：O(n) — 递归栈 + path

易错点

  • 回溯恢复 path：切下后要 pop，否则方案之间互相污染
  • 前缀回文判断：用双指针或 sub==sub[::-1] 判断，别漏单字符（恒为回文）
自我检验

Q: s 全相同字符如 "aaa"？

答： 每个前缀都回文，方案数为 2^(n-1)，这是最坏情况。

Q: 如何优化回文判断？

答： 用 DP 预计算 pal[i][j]，把 isPal 从 O(n) 降到 O(1)。
