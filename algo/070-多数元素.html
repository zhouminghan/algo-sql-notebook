为什么用这个思路？
Boyer-Moore 投票：维护候选人和计数。遇到相同数 +1、不同数 -1，计数归零就换候选人。多数元素出现次数超过一半，最终幸存者必是它。

题目描述

给定大小为 n 的数组，返回其中的多数元素。多数元素指在数组中出现次数大于 ⌊n/2⌋ 的元素。保证一定存在。

示例：
[2,2,1,1,1,2,2] → 2

图解即思路

① 候选人 cand，计数 count：相同 +1、不同 -1
② 最终幸存者 2 即多数元素
结论
多数元素出现次数过半，「抵消」不掉，投票结束后仍存活。

最优解代码

Python

def majorityElement(nums):
    cand = count = 0
    for x in nums:
        if count == 0:
            cand = x
        count += 1 if x == cand else -1
    return cand

Java

public int majorityElement(int[] nums) {
    int cand = 0, count = 0;
    for (int x : nums) {
        if (count == 0) cand = x;
        count += (x == cand) ? 1 : -1;
    }
    return cand;
}

复杂度分析

  • 时间：O(n)
  • 空间：O(1)

易错点

  • count==0 换候选人：抵消完后，下一个元素成为新候选人
  • 前提是多数元素存在：题目保证一定存在；若不确定，最后要再遍历验证一次
自我检验

Q: 为什么投票法成立？

答： 多数元素次数 > n/2，任何其它元素集合的总数都 < n/2，抵消到最后必有剩余，且剩余者就是多数。

Q: 若不一定存在多数元素？

答： 投票后需再扫描一遍确认 cand 次数是否真的 > n/2，否则返回无解。
