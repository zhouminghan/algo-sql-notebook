为什么用这个思路？
BST 中序遍历严格递增，第 k 个访问到的节点就是第 k 小。迭代中序（或递归计数）到第 k 个即停，不必遍历整棵树。

题目描述

给定二叉搜索树的根节点和一个整数 k，返回树中第 k 小的元素（从 1 开始计数）。

示例：
树 [3,1,4,null,2], k=1 → 1；k=3 → 3

图解即思路

① 中序遍历顺序：1,2,3,4
② 第 k 个访问到的即第 k 小
结论
中序第 k 个节点就是答案，计数到 k 提前停止。

最优解代码

Python

def kthSmallest(root, k):
    stack = []
    cur = root
    while True:
        while cur:
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        k -= 1
        if k == 0:
            return cur.val
        cur = cur.right

Java

public int kthSmallest(TreeNode root, int k) {
    Deque<TreeNode> st = new ArrayDeque<>();
    TreeNode cur = root;
    while (true) {
        while (cur != null) { st.push(cur); cur = cur.left; }
        cur = st.pop();
        if (--k == 0) return cur.val;
        cur = cur.right;
    }
}

复杂度分析

  • 时间：O(h + k) — 访问到第 k 个即停
  • 空间：O(h) — 栈

易错点

  • 中序第 k 个：中序严格递增是前提，遍历到第 k 个返回
  • 迭代避免全遍历：找到第 k 个立刻返回，不必走完整棵树
自我检验

Q: k 越界？

答： 题目保证 k 有效（1 ≤ k ≤ 节点数），无需处理。

Q: 进阶：频繁插入删除的 BST？

答： 给节点维护「左子树大小」计数，O(h) 定位第 k 小。
