为什么用这个思路？
路径可以不过根、只走一部分。递归时每个节点返回「以它为起点向下延伸的最大单边和」，同时用「左单边 + 自己 + 右单边」更新全局最大，负数边直接舍弃。

题目描述

二叉树中的路径，是任意节点间、每个节点至多经过一次的序列。路径和是路径上节点值的总和。返回所有路径中的最大路径和。

示例：
[1,2,3] → 6（2→1→3）；[-10,9,20,null,null,15,7] → 42（15→20→7）

图解即思路

① 每个节点返回「向下最大单边和」
② 20 的左右单边 15、7 都为正，弯折路径 15+20+7=42
结论
单边和 = max(0, 左单边) + max(0, 右单边) + 自身 更新答案；返回值只取较大一侧 + 自身。

最优解代码

Python

def maxPathSum(root):
    ans = [float('-inf')]
    def dfs(node):
        if not node:
            return 0
        left = max(dfs(node.left), 0)    # 负边舍弃
        right = max(dfs(node.right), 0)
        ans[0] = max(ans[0], left + right + node.val)  # 弯折路径
        return max(left, right) + node.val             # 向上单边
    dfs(root)
    return ans[0]

Java

int ans = Integer.MIN_VALUE;
public int maxPathSum(TreeNode root) {
    dfs(root);
    return ans;
}
int dfs(TreeNode n) {
    if (n == null) return 0;
    int l = Math.max(dfs(n.left), 0);
    int r = Math.max(dfs(n.right), 0);
    ans = Math.max(ans, l + r + n.val);
    return Math.max(l, r) + n.val;
}

复杂度分析

  • 时间：O(n)
  • 空间：O(h)

易错点

  • 负贡献舍弃：单边和与 0 取 max，负子树直接不选
  • 返回值与答案分开：返回「单边」给父节点用，答案用「弯折」更新，二者不能混
自我检验

Q: 全负节点怎么办？

答： 单边都被 0 截断，答案最终取到最大的那个负节点值（如 -3 是最大值）。

Q: 路径一定要经过根吗？

答： 不一定。答案是全局任意路径，这正是递归要在每个节点都更新 ans 的原因。
