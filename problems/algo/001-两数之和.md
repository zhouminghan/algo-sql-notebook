## 📖 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出**和为目标值** `target` 的那**两个**整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。

**示例 1：**
```
输入：nums = [2,7,11,15], target = 9
输出：[0,1]
解释：因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。
```

**示例 2：**
```
输入：nums = [3,2,4], target = 6
输出：[1,2]
```

**示例 3：**
```
输入：nums = [3,3], target = 6
输出：[0,1]
```

---

## 💡 解题思路

### 核心思想：哈希表一次遍历

- 暴力法：两层循环 O(n²)
- **优化**：遍历数组，对于每个元素 `nums[i]`，计算 `complement = target - nums[i]`
- 检查 `complement` 是否已经在哈希表中
  - 如果在 → 找到答案，返回 `[map[complement], i]`
  - 如果不在 → 把 `nums[i]` 和其下标存入哈希表

**复杂度**：时间 O(n)，空间 O(n)

---

## 🐍 Python 解法

```python
from typing import List

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        """
        哈希表一次遍历
        时间: O(n)  空间: O(n)
        """
        seen = {}  # {值: 下标}
        for i, num in enumerate(nums):
            complement = target - num
            if complement in seen:
                return [seen[complement], i]
            seen[num] = i
        return []  # 题目保证有解


# ===== 测试 =====
if __name__ == "__main__":
    s = Solution()
    assert s.twoSum([2, 7, 11, 15], 9) == [0, 1]
    assert s.twoSum([3, 2, 4], 6) == [1, 2]
    assert s.twoSum([3, 3], 6) == [0, 1]
    print("✅ 全部测试通过")
```

## ☕ Java 解法

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    /**
     * 哈希表一次遍历
     * 时间: O(n)  空间: O(n)
     */
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>(); // {值: 下标}
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (map.containsKey(complement)) {
                return new int[]{map.get(complement), i};
            }
            map.put(nums[i], i);
        }
        return new int[]{}; // 题目保证有解
    }
}
```

---

## 🧠 关键点

1. **为什么不用暴力双循环？** O(n²) 在大数据量下不可接受
2. **为什么用 HashMap？** 查找 O(1)，空间换时间
3. **为什么先查后存？** 避免同一个元素被使用两次（如 `nums=[3,3], target=6`）
4. **遍历顺序**：存的是已经遍历过的元素，查未遍历的补数，保证不会重复使用

---

## 🔄 易错点

- ❌ 先存后查 → 可能返回同一个元素两次
- ❌ 忘记考虑重复元素 → 哈希表 key 相同会覆盖，但先查后存不会有问题
- ❌ 返回的是**下标**不是**值**
