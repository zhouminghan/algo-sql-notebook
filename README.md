# algo-sql-notebook

算法 + SQL 图解题库 · 零构建 · 纯静态 · 桌面向

🌐 **在线访问**：[zhouminghan.github.io/algo-sql-notebook](https://zhouminghan.github.io/algo-sql-notebook/)

## 项目结构

```
algo-sql-notebook/
├── index.html              # 首页：题目索引（Tab 切换 算法/SQL）
├── assets/
│   ├── css/style.css       # 全局样式（表头/斑马纹/帧标签/分区色）
│   └── js/draw-utils.js    # SVG 绘图库（链表/树/DP表/窗口函数/Join 等 20+ 函数）
├── algo/                   # 算法题页面（LeetCode Hot 100）
└── sql/                    # SQL 题页面（字节/SHEIN 机试等）
```

## 启动

```bash
cd algo-sql-notebook
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 页面约定

每道 SQL 题包含：
- **题目描述** + 源数据表（表结构 SVG + 数据 SVG）
- **📖 业务术语**：题目涉及的业务概念解释
- **📐 图解即思路**：N 帧图解，每帧 = 完整 CTE 定义 + SVG 表格（分区着色）
- **📝 SQL 代码**：可一键复制的完整答案
- **⚠️ 易错点** + **🧪 自我检验**：常见坑和验证题
- **📦 本地复现**：可折叠的 CREATE TABLE + INSERT + 完整 SQL

所有帧的 pre code 按顺序拼接 = 完整答案。

## 命名约定

SQL 题：`NNN-{来源}题目名.html`（如 `002-shein新客回访复购分析.html`）

## 技术栈

Pico.css + highlight.js + 纯 SVG 内联绘图（CSS 变量适配暗色/亮色模式，表格随窗口自适应）
