为什么用自连接而不两次查询拼起来？
自连接 a.from_id = b.to_id AND a.to_id = b.from_id 一次扫表，JOIN 条件是「A→B 且 B→A」的精确对称匹配。加 a.from_id < a.to_id 去重保证每对只出一行，避免 (1,2) 和 (2,1) 重复输出。

业务术语

术语含义
from_id关注发起方用户 ID
to_id被关注方用户 ID
互相关注（互关）A 关注 B 且 B 也关注 A，即双向关注关系

题目描述

字节跳动面试题。表 c22_follow 每行表示"用户 from_id 关注了 to_id"。找出所有互相关注的用户对（A 关注 B 且 B 关注 A）。每对只输出一次（小 id 作为 user_a 在前），按 user_a、user_b 升序排列。

c22_follow（关注关系表）
每行 = 一条关注关系。互关需要在表中存在对称的两行

图解即思路

① 自连接 — A→B 且 B→A 的对称匹配
SELECT a.from_id, a.to_id, b.from_id, b.to_id
FROM c22_follow a
JOIN c22_follow b
  ON a.from_id = b.to_id AND a.to_id = b.from_id
-- 此时 (1,2) 和 (2,1) 各出现一次，需要去重
② 最终输出 — WHERE a.from_id < a.to_id 去重，小 id 在前
SELECT a.from_id AS user_a, a.to_id AS user_b
FROM c22_follow a
JOIN c22_follow b
  ON a.from_id = b.to_id AND a.to_id = b.from_id
WHERE a.from_id < a.to_id
ORDER BY user_a, user_b;

以上 2 帧的 SQL 按顺序拼接，即为完整答案。

SQL 代码

SELECT a.from_id AS user_a, a.to_id AS user_b
FROM c22_follow a
JOIN c22_follow b
  ON a.from_id = b.to_id AND a.to_id = b.from_id
WHERE a.from_id < a.to_id
ORDER BY user_a, user_b;

易错点

  • 去重用 < 而非 <>：a.from_id < a.to_id 保证每对互关只输出一行（小 id 在前）。如果不用 < 直接用自连接结果，(1,2) 和 (2,1) 都会输出 — 违反了"每对只输出一次"的要求。
  • JOIN 条件必须双向对称：ON a.from_id=b.to_id AND a.to_id=b.from_id 不能只写一个方向只匹配一半。
  • 不需要 DISTINCT：由于 a.from_id < a.to_id 且互关在表中是唯一的对称对，自连接 + < 已经天然去重，无需额外 DISTINCT。
本地复现（CREATE TABLE + INSERT + SQL） 
CREATE TABLE c22_follow (
    from_id INT,
    to_id INT
);
INSERT INTO c22_follow VALUES
(1, 2), (2, 1),    -- 互关 ✓
(1, 3),             -- 1→3 单向
(3, 4),             -- 3→4 单向
(4, 5), (5, 4),    -- 互关 ✓
(2, 5);             -- 2→5 单向

SELECT a.from_id AS user_a, a.to_id AS user_b
FROM c22_follow a
JOIN c22_follow b
  ON a.from_id = b.to_id AND a.to_id = b.from_id
WHERE a.from_id < a.to_id
ORDER BY user_a, user_b;

-- 期望结果：
-- user_a | user_b
--      1 |      2
--      4 |      5
自我检验

Q1: 如果表里只有 (1,2)、(2,3)、(3,1) 三条，有互关吗？

答： 没有。三条组成单向环（1→2→3→1），但没有任何一对是双向的。自连接匹配不到任何行。

Q2: 如果改成「找出被至少 2 人关注的用户」，SQL 怎么改？

答： 不需要自连接，直接 GROUP BY + COUNT 即可。

SELECT to_id, COUNT(*) AS fan_cnt
FROM c22_follow
GROUP BY to_id
HAVING COUNT(*) >= 2
ORDER BY to_id;
