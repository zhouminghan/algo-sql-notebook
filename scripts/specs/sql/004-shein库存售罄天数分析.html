为什么用 ROW_NUMBER + 日期窗口而不是自连接？
4.1 取最后一次有 qty 的记录：ROW_NUMBER DESC 一次扫描搞定，比 MAX(date) 再 JOIN 回来取 qty 简洁。
4.2 售罄天数 = 数据段总天数 − 有库存天数：用 DATEDIFF(MAX, MIN) + 1 减 COUNT(DISTINCT date)，无需生成日历表逐天判断。

业务术语

术语含义
market平台编码，如 AMZ=亚马逊美国、US=美国站、WAL=沃尔玛
SKUStock Keeping Unit，单品唯一标识
qty当天的库存数量
售罄天数数据段内没有库存记录的天数 = 总天数 − 有库存天数

题目描述

SHEIN 机试题。表 shein_C 记录每个 market 每个 sku 每天的 qty：

shein_C（库存流水表）
每行 = 某平台某 SKU 某天的库存量

4.1 每个 market 每个 sku 最后一次有 qty 的时间及 qty

4.2 售罄天数 = 数据段总天数 − 有库存天数

图解即思路

① CTE: ranked — ROW_NUMBER 按日期倒序，rn=1 即最后一天
WITH ranked AS (
    -- ① 按 market+sku 分区，日期倒序编号
    SELECT market, sku, qty, date,
           ROW_NUMBER() OVER (PARTITION BY market, sku ORDER BY date DESC) AS rn
    FROM shein_C
),
② 4.1 答案 — 取 rn=1 即最后一次有 qty 的记录
SELECT market, sku, date AS last_date, qty AS last_qty
FROM ranked
WHERE rn = 1
ORDER BY market, sku;
③ CTE: stats — 按 market+sku 聚合日期范围与有库存天数
stats AS (
    -- ③ 计算数据段总天数 DATEDIFF(MAX,MIN)+1 与有库存天数 COUNT(DISTINCT date)
    SELECT market, sku,
           DATEDIFF(MAX(date), MIN(date)) + 1 AS total_days,
           COUNT(DISTINCT date) AS stock_days
    FROM shein_C
    GROUP BY market, sku
)
④ 4.2 答案 — 售罄天数 = 总天数 − 有库存天数
SELECT market, sku,
       total_days,
       stock_days,
       total_days - stock_days AS sold_out_days
FROM stats
ORDER BY market, sku;

以上 4 帧的 SQL 按顺序拼接（4.1 和 4.2 各为独立查询），即为完整答案。

SQL 代码

-- 4.1 每个 market 每个 sku 最后一次有 qty 的时间及 qty
WITH ranked AS (
    SELECT market, sku, qty, date,
           ROW_NUMBER() OVER (PARTITION BY market, sku ORDER BY date DESC) AS rn
    FROM shein_C
)
SELECT market, sku, date AS last_date, qty AS last_qty
FROM ranked
WHERE rn = 1
ORDER BY market, sku;
-- 4.2 每个 market 每个 sku 的售罄天数
WITH stats AS (
    SELECT market, sku,
           DATEDIFF(MAX(date), MIN(date)) + 1 AS total_days,
           COUNT(DISTINCT date) AS stock_days
    FROM shein_C
    GROUP BY market, sku
)
SELECT market, sku,
       total_days,
       stock_days,
       total_days - stock_days AS sold_out_days
FROM stats
ORDER BY market, sku;

易错点

  • 4.1 不能直接用 MAX(date) + JOIN：MAX(date) 找到日期后还要 JOIN 回来取 qty，如果同一天有多条 qty（不同时间），MAX 后再 JOIN 会取到多条。ROW_NUMBER DESC 按日期分区精确取最后一条，避免歧义。
  • 4.2 总天数 = DATEDIFF + 1 而非直接 DATEDIFF：比如 2/1 ~ 2/3 是 3 天，DATEDIFF('2023-02-03','2023-02-01') = 2，需要 +1。
  • 有库存天数用 COUNT(DISTINCT date) 而非 COUNT(*)：同一天同 sku 可能有重复记录，用 DISTINCT 避免重复计数。

自我检验

Q1: 如果 AMZ/Label-1 在 2/2 有两条 qty 记录（不同时间），ROW_NUMBER DESC 取到哪条？

答： 取 rn=1 的那条。如果 ORDER BY 只有 date DESC 没有 tie-breaker，同一天多条记录顺序不确定。如需精确控制，可加第二个排序列如 ORDER BY date DESC, qty DESC。

Q2: 示例数据中所有 sku 售罄天数都是 0，什么情况下会 > 0？

答： 当某个 sku 在数据段中间某天没有记录时。比如 AMZ/Label-1 有 2/1 和 2/3 但没有 2/2 → total_days=3, stock_days=2 → sold_out_days=1。
